# AI Archive Video Automation

AI Archive Video Automation is a project for creating documentary-style videos from historical research materials, archival references, articles, and related sources.

This public repository serves as the project's public information and contact page.

## Project Purpose

The project is designed to support a research-to-video workflow including:

- Research and reference collection
- Historical source organization
- Research brief creation and review
- Evidence-aware script drafting
- Scene planning
- Visual and audio production assistance
- Preview and final video production

## Wikipedia Integration

AI Archive optionally uses the official MediaWiki API to help users search for and import Wikipedia articles as research references.

Wikipedia integration is:

- Optional and user initiated
- Limited to official Wikimedia / MediaWiki APIs
- Used for research references only
- Not used for automated web scraping
- Not used to automatically download Wikipedia images or videos
- Not treated as automatic factual verification

Wikipedia references are incorporated into the project's existing research and review workflow before they are used for script development.

## API Identification

This repository is provided as the public project and contact reference for API requests made by AI Archive Video Automation.

API requests may identify this repository in the HTTP User-Agent so Wikimedia administrators can identify the application and its purpose.

## Privacy and Source Code

The production source code for AI Archive Video Automation is maintained separately.

This public repository does not contain private credentials, API keys, user project data, production media, or other confidential information.
